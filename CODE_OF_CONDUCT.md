# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## In short
- Be kind and patient. People here range from first-time testers to seasoned developers, and newcomers'
  questions are welcome.
- Critique code and ideas, not people.
- No harassment, insults, discrimination, sexual content aimed at people, or sharing anyone's private
  information.
- Assume good faith, and say so when you're not sure what someone meant.

## Enforcement
Maintainers may edit or remove comments, issues and PRs that break these rules, and may block repeat or serious
offenders. To report a problem privately, use GitHub's **Report content** option on the comment or issue, or
contact the maintainers through the repository owner's GitHub profile. Reports are handled confidentially.

This applies in the repository's issues, pull requests and discussions, and anywhere someone represents the
project.
